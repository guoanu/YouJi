## 一、改造目标

### 1.1 一句话总结

将「快捷便签」的入口从右上角工具栏移到左侧边栏，与「新建笔记」并列，并在侧边栏中增加独立的分区来管理随心记和日程。

### 1.3 改动要点

| # | 改动 | 说明 |
|---|------|------|
| **1** | 快捷键按钮搬家 | 从右上角移到左侧边栏，与"新建笔记"并列 |
| **2** | 侧边栏增加 3 个可折叠分区 | 笔记（含现有分类）/ 随心记（平铺）/ 日程（平铺） |
| **3** | 数据按类型分离存储 | 笔记、随心记、日程通过 `kind` 字段区分 |
| **4** | 搜索跨类型检索 | 搜索框同时检索三种内容 |

### 1.4 不变的部分

- 随心记窗口（NotePad）的**行为完全不变**：小窗编辑、Ctrl+Space 呼出、窗口池预热、保存为磁贴等
- 现在右上角的「快捷便签」按钮**搬到侧边栏**，功能一模一样
- 全局快捷键 `Ctrl+Space` 保持不变

## 二、数据类型设计

三种内容在数据结构上完全一致，仅通过 `kind` 字段区分：

```typescript
export type ContentKind = "note" | "freeNote" | "schedule";
```

| 类型 | kind 值 | 编辑窗口 | 分类支持 | 侧边栏分区 |
|------|---------|----------|----------|------------|
| 笔记 | `"note"` | 主窗口 | ✅ 有（文件夹） | 📋 笔记 |
| 随心记 | `"freeNote"` | NotePad 小窗 | ❌ 无 | 💬 随心记 |
| 日程 | `"schedule"` | 主窗口 | ❌ 无 | 📅 工作日日程 |

### TypeScript 类型变更

只比现有类型多一个 `kind` 字段：

```typescript
// src/features/notes/types.ts

export interface NoteMetadata {
  // ... 现有字段不变 ...
  kind: ContentKind;        // 新增，默认 "note" 兼容旧数据
}

export interface SaveNoteRequest {
  // ... 现有字段不变 ...
  kind: ContentKind;        // 新增
}
```

### 旧数据兼容

`metadata.json` 中已有的笔记没有 `kind` 字段，加载时默认设为 `"note"`。用户无感知。

## 三、后端改造

### 3.1 Rust struct 变更

`NoteMetadata`、`SaveNoteRequest` 各加 `kind: String`。

- `"note"` → 笔记
- `"freeNote"` → 随心记
- `"schedule"` → 日程

### 3.2 新增 Tauri Command

```rust
// 按类型过滤笔记列表
#[tauri::command]
fn notes_list_by_kind(kind: String) -> Result<Vec<NoteMetadata>, AppError> {
    default_store()?.list_notes_by_kind(&kind)
}
```

其余 `notes_create`、`notes_update`、`notes_delete` 保持现有签名不变，`kind` 通过 `SaveNoteRequest` 传入。

### 3.3 文件改动

| 文件 | 改动 |
|------|------|
| `src-tauri/src/services/notes.rs` | struct 加 `kind`；新增 `list_notes_by_kind()` |
| `src-tauri/src/lib.rs` | 注册 `notes_list_by_kind` command |

## 四、前端改动

### 4.1 侧边栏四个按钮

```tsx
<div className="px-3 pb-2 shrink-0 space-y-1">
  {/* 1. 新建笔记 */}
  <button onClick={handleNewNote}>           // kind: "note"
    [+ 新建笔记]
  </button>

  {/* 2. 新建随心记 — 从右上角搬下来的 */}
  <button onClick={handleNewFreeNote}>       // kind: "freeNote", 打开 notepad 窗口
    [✎ 新建随心记]  <kbd>Ctrl+Space</kbd>
  </button>

  {/* 3. 新建日程 */}
  <button onClick={handleNewSchedule}>       // kind: "schedule"
    [📅 新建日程]
  </button>

  {/* 4. 导入 Markdown — 保持不变 */}
  <button onClick={handleImportNote}>
    [↑ 导入 Markdown]
  </button>
</div>
```

### 4.2 三个可折叠分区

```tsx
<div className="flex-1 overflow-y-auto px-2 pb-2">
  {/* 分区一：📋 笔记 */}
  <CollapsibleSection title="笔记" count={notes.length}>
    {/* 完全复用现有分类 + 笔记列表 */}
  </CollapsibleSection>

  {/* 分区二：💬 随心记 */}
  <CollapsibleSection title="随心记" count={freeNotes.length}>
    {/* 平铺列表，点击 → openNotepadWindow(noteId) */}
    {freeNotes.map(n => <FreeNoteItem key={n.id} note={n} />)}
  </CollapsibleSection>

  {/* 分区三：📅 工作日日程 */}
  <CollapsibleSection title="工作日日程" count={schedules.length}>
    {/* 平铺列表，点击 → 在主窗口编辑器中打开 */}
    {schedules.map(s => <ScheduleItem key={s.id} note={s} />)}
  </CollapsibleSection>
</div>
```

### 4.3 右上角工具栏

移除当前的「快捷便签」按钮（💬 图标），其余不变。
